# 🎬 Netflix Clone - Full Stack Project

A full-stack **Netflix-inspired web application** built using **Node.js, Express.js, MySQL, and Vanilla JavaScript**.

The application provides a Netflix-style interface with user authentication, TV show search, dynamic content, and a personalized watchlist.

> This is an educational project inspired by Netflix and is not affiliated with Netflix, Inc.

## ✨ Features
- 🎨 Netflix-inspired responsive UI
- 🔐 User Sign Up and Sign In
- 🔑 Password hashing using bcryptjs
- 👤 Session-based authentication
- 🔎 TV show search
- 🎬 Dynamic TV show content using TVMaze API
- ❤️ Add and remove shows from My List
- 💾 MySQL database for users and watchlists
- ⭐ Show ratings and details
- ❓ Interactive FAQ section
- 📱 Responsive design for desktop, tablet, and mobile
